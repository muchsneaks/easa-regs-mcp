Questions.




What is an MCP server?
The Model Context Protocol (MCP) is an open standard that lets AI assistants such as Claude use external tools. easa-regs is one of those tools: Claude uses it to search the EASA regulations before it answers.


Does it cost anything?
No. easa-regs is free and open source (MIT licence). All you need is Claude, and the Free plan is enough for one custom connector.


Is this official EASA software?
No. easa-regs uses EASA's official, machine-readable Easy Access Rules, but it is an independent project and not legally binding. Only the texts published in the Official Journal of the EU are authentic.


How current are the rules?
Every Monday easa-regs automatically syncs with the EASA data. Every answer states the revision it is based on.


Claude is not using easa-regs. What now?
Check that the connector is enabled in the chat (the “+” menu › Connectors). You can also ask Claude directly: “Use easa-regs and quote the rule.”


What data is stored?
easa-regs stores no accounts and no chat histories. With the hosted connector, only the search query itself reaches the server. The local version runs entirely on your machine.


Are national rules included?
Not yet. It covers EASA's EU regulations. National rules, AICs or the national AIP are not included.
